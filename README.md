# 🚀 Eixo: Linguagens de Programação

Bem-vindo ao repositório de apoio voltado para o domínio das linguagens de programação mais requisitadas pelo mercado atual. Este material foi construído com base nas necessidades reais apontadas pelos próprios alunos em nosso levantamento inicial.

## 🎯 Por que Python?
Python é amplamente utilizado para o ensino de lógica de programação e desenvolvimento de sistemas [1]. A linguagem destaca-se pela sua sintaxe clara, permitindo a construção e o controle de fluxos de decisão de maneira simples e legível [1, 2].

## 📂 Conteúdos Disponíveis

### 🐍 [Python](./python)
Foco em **Introdução à Programação e Estruturas Condicionais**.
- **Conceitos Chave:**
  - Desvio de fluxo de execução de programas e representação por fluxogramas.
  - Condicionais simples e compostas utilizando `if` e `else`.
  - Condicionais aninhadas e encadeamento com `elif`.
  - Operadores lógicos (`and`, `or`, `not`) para construção de condições compostas.
  - Estrutura de seleção múltipla (*pattern matching*) com `match` e `case`.
- **Ferramentas e Práticas:**
  - **VS Code:** Execução de scripts `.py` através do terminal integrado.
  - **Python 3:** Execução de códigos via linha de comando.
  - **Indentação:** Regras de alinhamento de bloco usando a tecla `Tab`.

---

## 🛠️ Como começar?
1. Certifique-se de ter o **Python 3** instalado em seu sistema.
2. Recomendamos o uso do **VS Code** com a abertura de um terminal integrado (`Terminal > New Terminal`) para rodar os arquivos de aula.
3. Preste bastante atenção à **indentação** dos blocos de código (tecla `Tab`), indispensável para a correta execução em Python.
