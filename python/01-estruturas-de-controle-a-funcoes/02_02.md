# String
AH! Textos! Parece ser algo tão simples, mas acaba por ser... mais difícil para o computadorzinho... Mas o Python oferece opções que facilitam nossa visa como programador.

Primeiro, relembrando, uma String na realidade é uma lista de caracteres organizados. Algo que não se deve se importar aqui no Python, mas todos os textos terminam com uum caracter especial chamado de `zero`, que seriam o `\0`. Quando o computador esbarra nele, ele começa a interpretar o vetor como um texto.

Como uma String é uma lista, todos os métodos de array funciona com ele, mas ele acaba por ter métodos e funções a mais! Aqui nesta aula veremos eles.

## Métodos de Alinhamentos

### str.center(width,fillchar=" ")
Este método irá pegar um texto e centralizar ele numa largura (o `width`). Se esta largura for menor que o texto, nada é feito. Caso queira, dá para indicar um *char* (caracter) para preencher o espaço em branco com o *fillchar*.
```python
valor = "Olá!!"

print(valor.center(20))
#'       Olá!!        '

print(valor.center(20, "-"))
#'       Olá!!        '
```

### str.ljust(width, fillchar=" ")
Retorna uma String que vai ser alinha a esquerda, em que vai ter o tamanho do *width* e o espaço em branco será preenchido com o *char* (caracteres) indicado no *fillchar*. Caso o len(str) for maior que o *width*, retorna a String normal.
```python
print("Python".ljust(20))
# 'Python              '

print("Python".ljust(20, "-"))
# 'Python--------------'

print("Python".ljust(20, ""))
"""
Traceback (most recent call last):
  File "<python-input-8>", line 1, in <module>
    "Python".ljust(20,"")
    ~~~~~~~~~~~~~~^^^^^^^
TypeError: The fill character must be exactly one character long
"""
```

### str.rjust(width, fillchar=" ")
Retorna uma String que vai ser alinha a direita, em que vai ter o tamanho do *width* e o espaço em branco será preenchido com o *char* (caracteres) indicado no *fillchar*. Caso o len(str) for maior que o *width*, retorna a String normal.
```python
print("Python".ljust(20))
# 'Python              '

print("Python".ljust(20, "-"))
# 'Python--------------'

print("Python".ljust(20, ""))
"""
Traceback (most recent call last):
  File "<python-input-8>", line 1, in <module>
    "Python".ljust(20,"")
    ~~~~~~~~~~~~~~^^^^^^^

"""
```

## Métodos de buscas

### str.count(texto[, inicio[, final]])
Ele conta a ocorrência de um texto na String. Por padrão, ele começa da primeira ocorrência, mas ele pode se definir quando ele inicia e quando ela acaba.
```python
valor = "Textos dentro de um Texto que também é um Texto"
print(valor.count("Texto")) # 3
print(valor.count("Texto", 2)) # 2
print(valor.count("Texto", 3))
```

### str.find(texto[, start[, end]])
Ele vai encontrar um sub texto em uma String, em que se pode definir o começo (`start`) e fim (`end`) de uma string.
```python
texto = "texto, texto, não, texto"

print(texto.find("ext")) # 1
print(texto.find("ext", 2)) # 8
print(texto.find("ext", 9, 20)) # -1 (indica que não encontrou)
```

#### in
O `in` é bem semelhante ao `.find()`, mas ao invés de informação a posição, informa se o sub texto está dentro ou não dentro da String.
```python
valor = "Texto"

print("ext" in valor) # True
print("dentro" in valor) # False
```

### str.rfind(texto[, start[, end]])
Busca um texto em uma String da direita para esquerda, devolvendo o indíce do primeiro caracter onde se inicia o texto. Caso não encontre, devolve o -1. Também pode-se indicar um interválo de posições onde vai pesquisar.
```python
print('spam, spam, spam'.rfind('sp'))
# 12

print('spam, spam, spam'.rfind('sp', 0, 10))
# 6
```

## Métodos de formatação

### str.strip(chars=None)
O `.strip()` remove os caracteres do começo e do final. Por padrão, ele remove os espaços vazios, mas pode indicar os que quer remover.
```python
print("    exemplo    ".strip())
# "exemplo"

print("exemplo".strip("eo"))
# "xempl"
```

### str.lstrip(char=None)
Este método remove do começo os caracteres especificado. Por padrão, remove os espaços vazios.
```python
print("    exemplo    ".lstrip())
# "exemplo    "

print("exemplo".lstrip("eo"))
# "xemplo"
```

### str.rstrip(char=None)
Este método remove do final os caracteres especificado. Por padrão, remove os espaços vazios.
```python
print("    exemplo    ".rstrip())
# "    exemplo"

print("exemplo".rstrip("eo"))
# "exempl"
```

### str.replace()
```python
print('spam, spam, spam'.replace('spam', 'eggs'))
# 'eggs, eggs, eggs'

print('spam, spam, spam'.replace('spam', 'eggs', 1))
# 'eggs, spam, spam'
```

### str.capitalize()
Este método irá pegar a string e retornar ela com o primeiro caracter em caixa econômico. Ele não modifica a original.
```python
texto = "um texto aqui"
print(texto.capitalize()) # Um texto aqui
```

### str.lower()
Retorna uma string em caixa baixa.
```python
print('Lower Method Example'.lower())
# 'lower method example'
```

## Métodos de partições

### str.join(interavel)
O `.join()` vai ficar responsável por concatenar Strings interáveis (em que é devolvido um erro *TypeError* caso o interável não seja uma String). O `str` será o elemento que vai juntar os itens do interável.
```python
print(" ".join(["spam", "de", "email"]))
# 'spam de email'

print("-".join("Python"))
# 'P-y-t-h-o-n'
```

### str.partition(sep)
Aqui a String vai ser divida em duas a partir da primeira ocorrência do separador (*sep*), retornando uma tupla com 3 elementos: todo elemento antes do separador, o separador, todos depois do separador. 

Caso não encontre o *sep*, ele devolver uma tupla com a String, dois espaços vazios.

```python
print('Monty Python'.partition(' '))
# ('Monty', ' ', 'Python')

print("Monty Python's Flying Circus".partition(' '))
# ('Monty', ' ', "Python's Flying Circus")

print('Monty Python'.partition('-'))
# ('Monty Python', '', '')
```

### str.rpartition(sep)
Seu funcionamento é semelhante ao `.partition()`, mas acaba por iniciar a separação pela direita.
```python
print('Monty Python'.rpartition(' '))
# ('Monty', ' ', 'Python')

print("Monty Python's Flying Circus".rpartition(' '))
# (("Monty Python's Flying", ' ', 'Circus')

print('Monty Python'.rpartition('-'))
# ('', '', 'Monty Python')
```

### str.split(sep=None, maxsplit=-1)
O `.split()` devolve uma lista com as palavras em que foram separadas através de um separador (*sep*) até um máximo elementos em uma lista (*maxsplit*). Ele inicia sua separação da esquerda para a direita.

Por padrão, o `split` separa por espaços em branco.

```python
texto = "Um texto, pelo visto, explicativo"
print(texto.split(" "))
# ['Um', 'texto,', 'pelo', 'visto,', 'explicativo']

print(texto.split())
# ['Um', 'texto,', 'pelo', 'visto,', 'explicativo']

print(texto.split(" ", 2))
# ['Um', 'texto,', 'pelo visto, explicativo']

print(texto.split(" ", 2))
# ['Um', 'texto,', 'pelo visto, explicativo']

```


## Verificadores de String
Agora vamos ver os métodos que irão verificar certas propriedades de um texto, como o tipo dele por exemplo. Estes métodos funciona em Strings com pelo menos um caracter.
### str.isalnum()
Ele retorna `True` se só a String contem letras e número, e `False` se ela contivesse caracteres especiais.
```python
('abc123'.isalnum())

'abc123!@#'.isalnum()

''.isalnum()

' '.isalnum()
```

### str.isalpha()
Verifica se a String só é compostas por caracteres do alfabeto, retornando `True`. Caso encontre algo fora do alfabeto, como o espaço, retorna falso.
```python
valor = "Texto Texto"

print(valor.isalpha()) # False

valor = "TextoTexto"

print(valor.isalpha()) # True
```

### str.isascii()
No mundo dos caracteres, temos diversos padrões de interpretação de um caracteres em um computador. Os mais famosos são o ASCII e UNICODE, em que o primeiro aborda o alfabeto norte-americano principalmente, e o segundo é uma tentativa de abrandir todos os alfabetos do mundo - já salvo diversos idiomas, como português e russo (por exemplo).

O `.isascii()` vai verificar se o texto entra no padrão do ASCII, retorna `True` se realmente for, `False` se não (String vazio é considerado dentro da norma ASCII).
```python
valor = 'Caracteres ASCII'

print(valor.isascii()) # True

valor = 'µ'

print(valor.isascii()) # False
```

### str.isdecimal()
Retorna `True` se todos os caracteres são decimais (pelo menos um número), `False` caso contrário. O método funciona até com caracteres de outros idiomas, como o arábico-índico (por conta de basear-se no padrão UNICODE).
```python
numeros = "012345"

print(numeros.isdecimal()) # True

numeros = "٠١٢٣٤٥٦٧٨٩" # Dígitos árabe-índico zero até nove

print(numeros.isdecimal()) # True

numeros = "texto"

print(numeros.isdecimal()) # False
```

### str.isdigit()
Ele verifica se é um dígito numérico. Diferente do decimal, ele considera também portências, por exemplo.
```python
numeros = "012345"

print(numeros.isdigit()) # True

numeros = "٠١٢٣٤٥٦٧٨٩" # Dígitos árabe-índico zero até nove

print(numeros.isdigit()) # True

numeros = "²"

print(numeros.isdigit()) # True
```

### str.isnumeric()
Aqui, o `.isnumeric()` expande os caracteres numéricos para todos que abrange o padrão UNICODE.
```python
numeros = "012345"

print(numeros.isdecimal()) # True

numeros = "٠١٢٣٤٥٦٧٨٩" # Dígitos árabe-índico zero até nove

print(numeros.isdecimal()) # True

numeros = "²"

print(numeros.isdecimal()) # True

# E fração
```

### str.isprintable()
Este verifica se o caracter é printável. Mas, como assim? Num texto temo caracteres que modificam o "comportamento" do texto em certas maneiras, como o `\n` que serve para pular linha num texto, ou o `\t` que indica tabulação de um texto.

Caso é printável, retorna `True` e `False` caso contrário.

```python
print('texto'.isprintable()) # True
print('\t'.isprintable()) # False
print('\n'.isprintable()) # False
```

### str.islower()
Verifica se um texto está todo em caixa baixo. Retorna `True` estiver em caixa baixo, `False` se contrário.
```python
print("texto".islower()) # True
print("Texto".islower()) # False
print("TEXTO".islower()) # False
```

### str.isupper()
Caso o texto todo está em caixa alta, ele retorna `True`, ou `False` caso contrário.
```python
print("texto".islower()) # False
print("Texto".islower()) # False
print("TEXTO".islower()) # True
```

### str.istile()
Verifica se os cada um dos textos separados estão com o primeiro caracter em caixa alta. Vendo o exemplo é possível entender melhor:
```python
print("Spam Spam Spam".istitle()) # True
print("Spam Spam spam".istile()) # False
print("spam spam spam".istitle()) # False
print("Spam, Spam, Spam".istitle()) # True
print("spam, spam, spam".istitle()) # False
```
